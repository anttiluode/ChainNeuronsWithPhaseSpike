# Source provenance
`chains/__init__.py, analysis.py, config.py, probing.py, world.py` are copied unchanged from
anttiluode/ComputationalChainsInPumpedGPUfield at commit `2b5511c` (29 Oct 2026). `chains/fork.py` is the
`fork_world` helper from that repo's `experiments/bond_ablation.py`, made standalone. Nothing in the physics
was modified. Experiment-level changes (pinned beads, ligation off, lowered test phase coupling in S3) are
set per experiment and labelled in the code and README.
